# Issue Tracker — Local Markdown

Issues live as markdown files under `.scratch/<feature-name>/` in this repo.

## Structure

```
.scratch/
  <feature-name>/
    ISSUE.md        — the issue description
    notes/          — working notes, research
    output/         — deliverables
```

## Conventions

- Issue filename: always `ISSUE.md`
- Each feature gets its own directory
- Stale directories (completed/abandoned) can be deleted or moved to `.scratch/_done/`
